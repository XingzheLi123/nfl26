1. Define a ‘chance’ as when a receiver reaches the line to gain, has at least 3.5 yard separation at decision frame, retains at least 2 projected yards after 0.5 seconds, and holds conditions for about 0.3 seconds. Define ‘actionable chance’ if receiver also has a window with no PFF hurry, hit, or sack.
2. Since actionable chance is just a chance when the offensive line held, and receivers are not responsible for failures of offensive line, if actionable chance per 100 dropbacks is a valid and useful statistics in evaluating a team’s performance, then chance created per 100 routes is a valid and useful statistics for evaluating a receiver.
3. Verified actionable chance leads to more first downs and yardage gained.
4. Verified actionable chance conceded correlates positively to first down conceded, touchdown conceded, and yardage allowed.
5. Conclusions: the following are useful stats for scouts
   a. chance created (evaluate receivers)
   b. first down and yardage gained when actionable chance exists (evaluate QB)
   c. actionable chance conceded (used to evaluate defense)
   d. chance to action ratio, called actionability rate (possibly evaluate offensive line).
